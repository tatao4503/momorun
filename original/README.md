# 루미 오리지널 샘플

루미는 특정 작품이나 캐릭터에 의존하지 않고 모모런의 캐릭터형 걷기 동료 구조를 보여 주기 위해 만든 오리지널 샘플입니다.

## 폴더 규칙

- 모모런이 직접 만든 캐릭터는 `www/original/<캐릭터 ID>/` 아래에만 둡니다.
- 팬 작품 기반 데이터와 이미지는 이 폴더에 넣지 않습니다.
- 캐릭터 코드, 아바타, 배경은 같은 캐릭터 폴더 안에서 함께 관리합니다.

## 제공 범위

- `Lite`: 오늘 걸음, 목표, 최근 7일, 짧은 산책 반응
- `Life`: HealthKit, 최근 기록, 알림, 기기 내장 TTS, 주간 기록
- `Full`: 노아 팬팩 전용이므로 제공하지 않음

루미 선택 상태에서 Full 주소로 직접 들어가면 Life로 돌아갑니다. 루미의 이름, 색상, 대표 이미지 설정은 노아 팬팩과 별도로 저장됩니다.

## 캐릭터 방향

- 이름: 루미
- 역할: 산책 기록을 함께 정리하는 밝고 차분한 동행자
- 인상: 짧고 물결치는 짙은 청록 머리, 코랄 머리핀
- 의상: 민트 윈드브레이커, 흰 운동 상의, 네이비 팬츠
- 소품: 디지털 산책 기록장
- 색상: 민트, 코랄, 하늘색

학교, 헤일로, 무기, 작품 로고와 같은 기존 팬팩의 고유 요소는 사용하지 않았습니다.

## 이미지 자산

- `www/original/lumi/mobile.jpg`: 세로형 산책 배경
- `www/original/lumi/avatar.jpg`: 정사각형 아바타
- `www/original/lumi/character.js`: 대사, 반응, 팔레트와 화면 설정

두 이미지는 앱의 오리지널 샘플을 위해 이미지 생성 도구로 새로 제작했습니다. 생성 요청에는 밝은 강변 공원, 걷는 동행자, 민트 운동복과 디지털 기록장을 지정하고 특정 작품·캐릭터·로고·텍스트와 닮지 않도록 명시했습니다.

이 기록은 자산의 제작 경위를 설명하기 위한 것이며 독점적 권리나 상표 등록을 주장하지 않습니다.
